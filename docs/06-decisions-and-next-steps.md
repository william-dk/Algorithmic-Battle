## 下一步（待用户确认后）

第一阶段的第一个里程碑，目标是"能在浏览器里看到几个算法在 2D 网格上圈地"：

1. 建仓库和包结构（见 03 的包划分），先只建 `engine`、`sdk`、`algorithms`、`web`。
2. 把原型里的规则改写成正式的引擎：`Topology`（2D 网格）、第一级规则、tick 循环、带种子的随机数。
3. 写确定性测试：同一份配置跑两遍，逐 tick 的结果必须完全一致。
4. 从原型移植三到四个算法（随机前沿、BFS、DFS、Voronoi 中线优先），每个算法附元数据。
5. 最简的 Canvas 2D 视图：地图、播放和暂停、速度。
6. 势力范围分析器和记分板。

之后依次是：回放与时间轴、其余算法和算法库界面、批量对战、3D。

原型脚本 `prototype/sim/gen.js` 是参考实现，可以对照它验证新引擎的结果，但它是一次性代码，不要直接当引擎用。
