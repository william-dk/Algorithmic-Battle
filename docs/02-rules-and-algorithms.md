# 02 · 规则与算法

这里记录的是原型模拟器（`prototype/sim/gen.js`）实际采用的规则和数值。它们是试出来的起点，不是定稿。标了"未实现"的是讨论过但原型里没有做的。

## 共同设定

- 格子有三种状态：空地、属于某一方、障碍。
- 2D 用 4 邻域，3D 用 6 邻域。
- 每一方开局只有一格"大本营"。
- 地图对称：四人图是四重镜像对称（随机障碍块镜像到四个象限，四角出生）；双人图是 180° 旋转对称。
- 随机数全部来自带种子的发生器，同一个种子复现同一局。

## 第一级：圈地

1. 每个 tick，每一方挑一个"与自己领地相邻的空格"。每 tick 可占的格数是配置项，原型里是 1。
2. 多方挑中同一格时，用带种子的随机数选一方，其余几方这个 tick 落空。
3. 所有人都无格可占时结束。格数最多的一方获胜。

### 要点：比的是圈地，不是填地

各方每 tick 占的格数相同，所以中盘时"已占格数"永远相等。差距来自谁把更多空地圈成了只有自己够得着。

因此记分板用"势力范围"：

- 势力 = 已占格数 + 圈下的空地
- 圈下的空地：从所有领地同时向空地做广度优先扩散，每块空地归最先到达的一方；同时到达算"等距争夺"，不归任何人。

原型里，这个指标在 2D 中盘相当接近终局；在 3D 早期只有粗略的参考价值。数据见 [05-prototype-findings.md](05-prototype-findings.md)。

## 第二级：攻伐

| 项目 | 原型里的取值 |
|---|---|
| 能量收入 | 每 tick `1 + 领地格数 / 150` |
| 能量上限 | 60 |
| 每 tick 行动次数 | 最多 6 次，每次每方提一个目标，能量不够就不提 |
| 占空地的花费 | 1 |
| 攻占敌格的花费 | `1 + 目标格周围的同色邻居数` |
| 大本营的额外防御 | +40 |
| 多方争同一格 | 带种子的随机数选一方；结算时仍须买得起、仍与目标相邻 |
| 补给线 | 每个 tick 结束时，与大本营断开连接的领地变成中立（空地） |
| 大本营被攻占 | 该方出局，全部领地变成中立 |

攻击花费的含义：平直战线上的格子，2D 里防御是 4，3D 里是 6；细长触手的尖端只有 2。阵型本身就是防御。

### 胜利条件

原型里实现的三条，按顺序检查：

| 顺序 | 条件 | 作用 |
|---|---|---|
| 1 | 只剩一方（其余大本营都被攻陷） | 决定性胜利 |
| 2 | 领先者占可用格 ≥ 60%，并保持 50 个 tick | 胜负已分时提前结束 |
| 3 | 到达 tick 上限（3,000），按领地数排名 | 保证一定结束 |

讨论过但未实现：

- 平局时比"全程领地累计值"（领地对时间的积分），让最后一刻偷袭和拖延都不划算。
- "加固"动作：花能量给自己的格子加防御。

### 原型里的四个示例 AI

它们只是为了让第二级的对局能跑起来，不是正式内容。

| 名称 | 选目标的规则（分数越小越优先） |
|---|---|
| 最小代价 | 花费 |
| 直取大本营 | 花费 + 0.3 × 到最近的存活敌方大本营的距离 |
| 稳扎稳打 | 花费 − 0.8 × 目标格周围的己方邻居数 |
| 切断者 | 优先打敌方的"细脖子"（只有相对两侧有同色邻居的格子），其次是空地和触手尖端 |

## 第一阶段的算法库：11 种经典算法

所有算法都是"前沿优先级策略"：维护一个候选集合（与自己领地相邻的空格），每个 tick 挑一个。

| 算法 | 分类 | 怎么挑 | 需要坐标 |
|---|---|---|---|
| BFS 广度优先 | 图遍历 | 最早发现的候选格（先进先出） | 否 |
| DFS 深度优先 | 图遍历 | 最新发现的候选格（后进先出）；新格的邻居按随机顺序入栈 | 否 |
| 随机前沿 | 随机生长 | 候选格里均匀随机挑一个（物理上叫 Eden 生长模型） | 否 |
| Prim 随机权重 | 随机生长 | 每个候选格发现时得到一个随机权重，挑权重最小的 | 否 |
| 随机游走 | 随机生长 | 上一格的随机空邻居；没有空邻居时随机挑一个候选格 | 否 |
| 螺旋 | 几何填充 | 按到大本营的方形圈层，圈内按角度顺序 | 是，仅 2D |
| 扫描线 | 几何填充 | 先比到大本营的行距，再比列距 | 是，仅 2D |
| Hilbert 曲线 | 几何填充 | 希尔伯特曲线序号与大本营序号之差最小的 | 是，仅 2D |
| A* 直取中心 | 启发式搜索 | `f = g + h` 最小；`g` 是从大本营走过来的步数，`h` 是到地图中心的曼哈顿距离；`f` 相同时先挑 `g` 大的 | 是 |
| 贪心最佳优先 | 启发式搜索 | 到最近敌方大本营的曼哈顿距离最小的 | 是 |
| Voronoi 中线优先 | 对抗圈地 | "到我方大本营的距离"与"到最近敌方大本营的距离"之差的绝对值最小的 | 是 |

后三种用到曼哈顿距离，2D 和 3D 都能算，所以都适用。

Voronoi 中线优先的行为：先笔直走到与对手等距的中线，再沿中线向两侧铺开筑墙，最后向内填充。它是原型里最强的算法。

### 还可以加的算法

讨论中提到、尚未实现：束搜索、蚁群、黏菌、元胞自动机式局部规则、Minimax、蒙特卡洛树搜索。第二级还可以有基于割点和最小割的"切断"类算法，因为补给线规则让图的连通性直接变成了战术。
